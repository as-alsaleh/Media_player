## Third-party code

Please do not paste code from GPL- or AGPL-licensed projects into this
repository. Several adjacent players — Jellyfin Media Player, FluentFin, Delfin,
Plezy — are GPL, and copying from them would relicense this project and make it
undistributable on the App Store. Reading them for reference is fine and often
useful; copying is not.

Adding a dependency is fine if its license is permissive (MIT, Apache-2.0, BSD,
MPL) or LGPL with dynamic linking. Flag anything else in the PR description.

## Building

```sh
# macOS app bundle
./scripts/bundle-macos.sh          # → apps/macos/.build/MediaPlayer.app

# Rust xcframework for iOS/tvOS, then the Xcode projects
./scripts/build-xcframework.sh
cd apps/ios && xcodegen generate
xcodebuild -project MediaPlayeriOS.xcodeproj -scheme MediaPlayeriOS build
```

The iOS/tvOS Xcode projects are generated by XcodeGen from
[`apps/ios/project.yml`](apps/ios/project.yml) — edit that file rather than the
generated `.xcodeproj`, since regenerating overwrites local changes.

## Scope

The UI in `apps/macos/Sources/MediaPlayer` is shared by macOS, iOS and tvOS.
Changes there affect all three platforms, so please check the `#if os(...)`
branches when touching anything platform-specific.

Network, metadata and streaming logic belongs in `core/mediacore` (Rust), which
exposes everything over a localhost HTTP API. Prefer adding to the engine over
adding networking to the Swift layer.
